# VXSStun

<img src="src/assets/icon.svg" width="72" alt="Логотип VXSStun">

Клиент для Android и Windows от **VenoXiss / vpnxis**.
Работает с вашими серверами и подписками. Встроенных серверов, регистрации
и платных функций нет.

Текущая версия: **0.0.1.alpha.1**. Проект находится в разработке:
перед постоянным использованием проверьте подключение на своём устройстве.

[Telegram](https://t.me/VenoXiss) · [Отчёт о тестировании](TEST_REPORT.md)

## Возможности

- VLESS/REALITY, VMess AEAD, Trojan, Shadowsocks, Hysteria2, WireGuard,
  SOCKS5 и HTTP/HTTPS proxy на базе Xray 26.7.28.
- Транспорты TCP, WebSocket, gRPC, XHTTP и HTTPUpgrade.
- Импорт из буфера обмена, текстового файла, списка ссылок, Base64,
  WireGuard `.conf` и QR-кода на изображении.
- Отдельные конфигурации и папки подписок. Поиск, избранное, сортировка,
  фильтр протокола и переименование папок.
- Обновление подписок по одной или всех сразу. Опциональное автообновление
  при открытом приложении.
- Отображение трафика, срока действия и объявлений, если их передаёт провайдер.
- TCP-пинг отдельного сервера или группы, остановка очереди проверок,
  выбор сервера с минимальным измеренным пингом.
- Статистика сеанса, журнал событий и повторное подключение при обрыве.
- Светлая и тёмная темы вслед за настройками устройства.

На Android используется системный VpnService. На Windows доступны TUN
для всего компьютера и локальные SOCKS/HTTP-прокси.

## Установка

### Android

Требуется Android 8 или новее и устройство ARM64.

1. Установите APK.
2. Добавьте конфигурацию или подписку.
3. Выберите сервер и нажмите «Подключить».
4. Подтвердите системный запрос на создание VPN-соединения.

При обновлении устанавливайте APK поверх предыдущей версии, без удаления
приложения — так сохранятся профили. Текущая alpha подписана debug-ключом
и не предназначена для публикации в магазинах приложений.

### Windows

Требуется Windows 10/11 x64 и Microsoft Edge WebView2 Runtime.

1. Распакуйте **весь ZIP** в отдельную папку.
2. Запустите `VXSStun.exe`. Каталог `runtime` должен оставаться рядом с ним.
3. Добавьте сервер и выберите режим подключения.

Для TUN нужны права администратора. Можно запустить EXE с нужными правами
или использовать перезапуск через UAC в приложении. Сам выбор режима прав
администратора не требует и не запускает соединение.

В режиме «Прокси» настройки Windows не меняются. Укажите показанный локальный
порт в приложении, которое должно использовать прокси.

Обновляйте EXE вместе с каталогом `runtime`: версии ядра проверяются по
контрольным суммам. Windows EXE пока не имеет подписи издателя.

## Конфигурации и подписки

Одиночная ссылка, добавленная через главный экран, попадает в «Мои конфигурации».

В разделе **Подписки → Добавить подписку** можно указать:

- HTTPS-ссылку провайдера — будет создана папка с обновляемым списком серверов;
- один ключ или несколько ключей — будет создана локальная папка без сетевого обновления.

Подписки принимаются как список URI или его Base64-представление. Ограничения:
100 записей и 256 КиБ на импорт, до 32 папок и 500 профилей в хранилище.
Требуется ответ HTTP 200; перенаправления и URL с логином не поддерживаются.

При обновлении сохраняются избранное и идентификаторы неизменившихся серверов.
Неудачное обновление не удаляет старый список. Если обновление меняет активный
сервер, сначала потребуется отключить соединение.

Автообновление выключено по умолчанию. После включения оно работает, пока
интерфейс приложения виден: по интервалу провайдера от 1 до 168 часов,
а при отсутствии интервала — раз в сутки. После ошибки повторная попытка
возможна не раньше чем через 5 минут.

QR-коды читаются из PNG, JPEG и WebP размером до 8 МиБ. Изображения
обрабатываются на устройстве; перед импортом можно проверить распознанные данные.

## Приватность и ограничения

Профили хранятся локально: Windows DPAPI или Android Keystore с AES-GCM.
Ссылки подписок сохраняются зашифрованными. Ключи не передаются интерфейсу
в списке профилей и не записываются в журнал. Android backup отключён.
В приложении нет аналитики и аккаунтов.

Обновление подписки обращается к её провайдеру. Проверка соединения использует
`https://www.gstatic.com/generate_204` через выбранный туннель. На Android
первичное разрешение адреса сервера выполняется через `1.1.1.1:53` по сокету
вне VPN, чтобы избежать петли маршрутизации.

**Собственного kill switch пока нет.** При аварийной остановке туннеля возможен
прямой выход в сеть. На Android можно включить системную блокировку соединений
без VPN. Статус «Подключён» подтверждает HTTPS-проверку, но не заменяет тест
DNS/IP-утечек.

Поддержка протокола не означает поддержку всех расширений провайдера:

- VMess: `alterId=0`, без устаревших типов заголовков.
- Hysteria2: TLS обязателен; obfs, port hopping и pinSHA256 пока не поддерживаются.
- WireGuard: один peer в `.conf`; hooks и скрипты не выполняются.
- TCP-пинг показывает доступность хоста, а не скорость VPN или успешную
  авторизацию. Для WireGuard и Hysteria2 он недоступен.
- SOCKS5 и обычный HTTP-прокси сами по себе не шифруют соединение с сервером.

Пока нет TUIC, OpenVPN, IKEv2, SSR, импорта произвольного Xray JSON/Clash YAML,
камеры и экспорта QR, split tunneling, фоновых обновлений при закрытом приложении,
Windows-сервиса и импорта VenoxyS Core. Неподдерживаемые параметры отклоняются,
а не игнорируются.

Подробнее: [безопасность](SECURITY.md).

## Сборка

Интерфейс — React и Tauri на Windows, WebView на Android.
Парсер профилей написан на Rust, Android-адаптер — на Kotlin.

Для сборки на Windows нужны:

- Node.js 22+ и Rust stable;
- Windows C++ Build Tools;
- JDK 17, Android SDK platform/build-tools 36;
- Android NDK 27.0.12077973 и Rust target `aarch64-linux-android`.

Задайте `JAVA_HOME`, `ANDROID_HOME` и при необходимости `ANDROID_NDK_HOME`.

```powershell
npm ci
rustup target add aarch64-linux-android
powershell -ExecutionPolicy Bypass -File scripts/prepare-runtime.ps1
```

Сборка Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

Сборка Android:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

Кэши находятся в `.build`, готовые пакеты — в `artifacts`.
Скрипты не устанавливают приложение и не подключают VPN.
В манифестах npm, Cargo и Tauri версия записана в формате SemVer:
`0.0.1-alpha.1`.

### Разработка и тесты

```powershell
npm run dev
npm test
cargo test --manifest-path crates/profiles/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
```

Для просмотра интерфейса без подключения откройте `/?preview=demo`.
Параметр `theme=dark` включает тестовую тёмную тему; `state=connected`,
`connecting`, `reconnecting`, `disconnecting` и `error` показывают состояния
кнопки. Демонстрационные данные не входят в production-сборки.
