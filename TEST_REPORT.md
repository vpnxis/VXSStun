# Проверка VXSStun 0.0.1.alpha.1 — 20.09.2026

## Выполнено для этой версии

- Production frontend, Windows release EXE и Android ARM64 APK собраны.
- 13 JS-тестов: формат, состояние кнопки, разделение конфигураций/папок,
  фильтры/сортировки, квоты, планировщик с backoff, локальное чтение QR.
- 29 Rust-тестов парсера/подписок; отдельно интеграционный тест 26 конфигураций
  реальным Xray 26.7.28 в режиме `-test` (не подключает VPN).
- 13 Windows-тестов: DPAPI, атомарность, хранилище/подписки, миграция настроек,
  переключение и сохранение TUN/прокси без запуска туннеля, разделение одинакового
  ключа между отдельными конфигурациями и папкой.
- 9 Android JVM-тестов; Kotlin/Gradle сборка успешна.
- Итого 65 автоматических тестов, включая один интеграционный тест с 26 случаями.
- Браузер: 320×568, 360×640, 390×780, 412×870, 600×900, 760×580, 1200×790;
  ширина подтверждена после resize. Нет переполнения html/workspace/content/заголовков.
- Светлая/тёмная темы, длинные названия, настройки на 320 px. Консоль без ошибок JS.
- Внизу мобильного списка край панели и начало навигации совпадают с точностью 1 px.
- Раздел подписок: только 2 папки/15 тестовых профилей, без 3 отдельных конфигураций;
  свернуть всё скрывает все строки; фильтр VLESS оставляет 5.
- Явная кнопка TUN в изолированном предпросмотре меняет состояние на выбранное.
  Этот UI-тест НЕ подтверждает реальную сетевую работу.
- QR PNG с тестовым VLESS на example.invalid прочитан в браузере; появился полный
  ключ и форма подтверждения. Сам импорт/подключение не выполнялись.
- Демо-профили/previewSnapshot отсутствуют в production dist. Одинаковые frontend
  assets скопированы в Android; старые файлы сохранены вне пакета в .build.
- npm audit --omit=dev: 0 известных уязвимостей на момент проверки.
- APK: app.vxsstun.client, 0.0.1.alpha.1, versionCode 5, minSdk 26, targetSdk 36,
  arm64-v8a. Подпись проверена; сертификат прежний:
  f7ff67580006e10dcaf1c5fa2c23f9213f5436d9df6c81c975695a28a7bd2586.
- ZIP и ELF LOAD alignment обеих .so — 16 КиБ.
- SHA-256 APK: 7318dfec7fedc92c0590a3f3ecb0e073df0a681fd4e41e4b7ff4d6ede922d98d.

## Что не проверялось

Реальный Windows TUN, DNS/IP-утечки, скорость и подключение к внешним
подпискам/серверам в рамках этой проверки не тестировались.
QR с камеры и с реальным Android file picker, фоновые обновления при закрытом
приложении не заявляются. Замеры браузера не заменяют аппаратную проверку safe area.
Пул Android TCP-проверок отделён от управления по коду; длительный нагрузочный
тест на физическом телефоне не проводился.

Gradle сообщает о deprecated Activity Result API / возможной несовместимости
будущего Gradle 9; текущая закреплённая 8.14.3 успешно собрала приложение.
Это alpha для тестирования; возможности и ограничения описаны в README.md.
Финальные хеши пакетов — artifacts/SHA256SUMS-0.0.1.alpha.1.txt.

# Проверка VXSStun 0.1.0-alpha.4 — 20.09.2026

## Мобильное исправление

- Vite production build и 6 JS-тестов — успешно; новая проверка подписей
  мобильной кнопки охватывает все 6 состояний и неизвестное значение.
- Android assembleDebug и 9 Kotlin JVM-тестов — успешно.
- APK: app.vxsstun.client, versionCode 4, 0.1.0-alpha.4, minSdk 26,
  targetSdk 36, arm64-v8a. Подпись v2 проверена, сертификат совпадает с alpha.3.
  ZIP/ELF LOAD alignment обеих нативных библиотек — 16 КиБ, проверка успешна.
- Браузерная проверка 320×568, 360×640, 390×780, 412×870, 600×900,
  760×580, 1200×790: переполнения по ширине html/workspace/content нет.
- Диаметр кнопки 164–184 px на мобильных размерах, на ПК сохранено 312×80
  при 1200×790. Мобильная подпись состояния скрыта на ПК; старый статус виден.
- Все шесть мобильных состояний проверены: текст помещается в кнопку,
  отдельный статус над ней скрыт, отключение блокирует повторное нажатие.
- Меню/плюс 48×48; при 390×780 «О программе» располагается в y=456–504,
  не у нижней системной границы; оставшееся пространство 276 px.
- Светлая и тёмная темы, узкие настройки, форма подписки при viewport 320×340:
  форма ограничена видимой областью, прокручивается, поле сохраняет фокус.
  Это имитация уменьшенной области, а не тест реальной Android-клавиатуры.
- Native insets перенесены в FrameLayout: это уменьшает размеры WebView;
  обработанные systemBars/displayCutout/IME обнуляются для потомка. Не добавляются
  к старому padding и не суммируют высоту клавиатуры с нижней системной панелью.
- При изменении темы не перезаписываются layout-флаги окна. Версия Android
  берётся из BuildConfig, Windows — из Cargo metadata (EXE не пересобирался).
- Сеть, маршруты, работающие VPN и подключённые устройства не переключались.
- Пустой список при 360×640: переполнения нет, нажатие «Подключить» открывает
  добавление конфигурации, а не попытку соединения без сервера.
- Финальные проверки APK и хеши: см. artifacts/SHA256SUMS-alpha.4.txt.

Ограничение: сборка не устанавливалась на физический телефон. Вырез камеры,
реальные жестовые/трёхкнопочные панели, поворот и системный масштаб шрифта
не проверялись на устройстве. Совместимость со всеми моделями не подтверждена.

# Проверка VXSStun 0.1.0-alpha.3 — 19.09.2026

## Выполнено

- Frontend собран из собственных npm-зависимостей VXSStun и package-lock.json.
- 5 JS-тестов: единицы трафика, неизвестные значения, таймер, состояния подключения,
  различение ссылок подписки и HTTPS-прокси в буфере.
- 26 Rust-тестов парсера/подписок: VLESS/Trojan/Shadowsocks/VMess/Hysteria2,
  WireGuard (dual-stack, запрет hooks), HTTP(S)/SOCKS5, Base64, атомарность импорта,
  запрет отключения проверки сертификата, отсутствие ключей в snapshot,
  loopback-прокси и отсутствие прямого обходного outbound. Для подписок —
  сохранение ID и избранного, отказ при удалении активного сервера,
  отказ при обновлении уже удалённой подписки, отсутствие URL/токена в snapshot,
  импорт Base64 с переносами строк и BOM.
- 10 Windows-тестов: DPAPI + проверка повреждённых данных, пустая установка,
  сохранение/чтение, дедупликация, удаление профиля, отмена некорректного импорта,
  сохранение подписки после перезапуска и неизменность хранилища при ошибке обновления,
  read-only модель готовности TUN, ограниченный список ссылок команды, Unicode-буфер.
- 1 интеграционный тест: Xray 26.7.28 проверил 26 конфигураций в режиме `run -test`
  (13 профилей × Proxy/TUN). Добавлена проверка точной версии runtime, поскольку
  старое ядро молча игнорировало неподдерживаемые поля маршрутизации.
  Тест не запускал TUN и не менял маршруты.
- 9 Kotlin-тестов: контракт `configJSON`, FD, локальные адреса служебных портов,
  отсутствие встроенных серверов, статистика, недопустимые параметры,
  сохранение параметров Hysteria2/WireGuard при передаче в libXray,
  запрет открытия произвольных URL через команду community links.
  Итого 51 тестовая функция — успешно.
- Чистая ARM64 debug APK-сборка; идентификатор `app.vxsstun.client`,
  версия `0.1.0-alpha.3`, versionCode 3, minSdk 26, targetSdk 36.
  После чистой сборки выполнена финальная пересборка с последними web-assets.
- APK Signature Scheme v2 проверена Android apksigner.
- ZIP/ELF LOAD alignment обеих библиотек: 16 КиБ, ABI arm64-v8a.
- Windows x64 release EXE собран с отдельным кэшем и актуальным pinned runtime.
  GUI, UAC и реальный TUN в рамках этой проверки не запускались.
- Визуально проверены отдельная мобильная и сохранённая десктопная компоновки,
  светлая/тёмная палитра, панель добавления и форма подписки, поиск и избранное,
  страница команды, сброс прокрутки при смене раздела.
- Размеры 360×800, 390×844, 412×915, 800×640, 1200×790: горизонтального overflow нет.
  Шесть состояний интерфейса проверены в явно обозначенном демо-режиме:
  disconnected, connecting, connected, reconnecting, disconnecting, error.
  Кнопка во время отключения недоступна; при ошибке показывает «Повторить».
- Фокус мыши без outline, клавиатурный фокус с салатовой рамкой; выделение обычного
  текста отключено, поля редактируемы. Стрелки scrollbar скрыты, ползунок оформлен
  в палитре темы. На Android отключены отдельные нативные полосы WebView.
- Демо-профили только в Vite DEV: в production dist нет demo-sub/example.invalid.
  Тёмный предпросмотр не менял тему ОС. Нативный VPN в ходе проверки не запускался.
- `npm audit --omit=dev`: известных уязвимостей production npm-зависимостей не найдено
  на момент проверки. Это не аудит Rust/Go/Android и не доказательство безопасности.
- Сгенерированные Android web-assets заменены актуальным dist; старые копии
  перенесены в .build, не попадают в APK или исходный архив.
- Разделены кэши standalone Rust-парсера и Tauri в build-windows.ps1:
  общие cdylib/rlib-артефакты разных графов зависимостей конфликтовали при повторном прогоне.
- Проверен исходный код на прежние инфраструктурные адреса/регистрацию: не найдены.

## Не проверено в поле

- Реальное подключение пользовательских конфигураций на Android и Windows.
- Windows TUN, UAC, переключения Wi-Fi/LTE, Doze, долгие сеансы и leak tests.
- Работа VPN после аварийного завершения: собственного kill switch в alpha нет.
- Автосмена темы на физическом Android. Реализована через тему Activity/WebView;
  UI пересоздаётся при смене темы, foreground VPN-служба не перезапускается.
- Полная совместимость всех вариантов ссылок Happ: поддерживаемое подмножество
  перечислено в README. Ни QR, ни произвольный JSON, ни VenoxyS Core не заявлены.
